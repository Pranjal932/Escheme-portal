# 🏛️ E-Scheme Portal — Zilla Parishad Nagpur

> **जिल्हा परिषद नागपूर | Gram Panchayat E-Scheme Portal | Maharashtra**

A comprehensive digital portal for Zilla Parishad Nagpur that provides citizens easy access to all Central and State Government welfare schemes, scholarships, and services.

## ✨ Features

- 🏠 **Government Portal UI** — Official-looking design with Indian emblem, tricolor strip, and leadership sticker
- 📋 **Scheme Catalog** — Browse all Central & State government welfare schemes with filters
- 🎓 **Scholarship Section** — Dedicated section for rural scholarships
- 🔍 **Eligibility Checker** — Check your eligibility for various schemes
- 📄 **Document Verification** — Step-by-step document verification guide
- 👤 **User Profile** — Personal profile with scheme tracking
- 🛡️ **Admin Panel** — Administrative dashboard for managing schemes
- 🌐 **Multi-language Support** — Full translations in **Marathi (मराठी)**, **Hindi (हिंदी)**, and **English**
- ♿ **Accessibility** — Font size controls, high contrast mode, and screen reader support
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices
- 📢 **News Ticker** — Live announcements and scheme updates

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v16 or higher)
- npm (comes with Node.js)

### Installation

```bash
# Clone the repository
git clone https://github.com/aashukamblee-cloud/Escheme-portal.git

# Navigate to the project
cd Escheme-portal

# Install dependencies
npm install

# Start the development server
npm run dev
```

The app will be running at **http://localhost:5173/**

### Production Build

```bash
npm run build
```

The optimized build files will be in the `dist/` folder.

## 🌐 Multi-Language Support

The portal supports three languages with a centralized i18n translation system:

| Language | Code | Status |
|---|---|---|
| मराठी (Marathi) | `mr` | ✅ Default |
| हिंदी (Hindi) | `hi` | ✅ Complete |
| English | `en` | ✅ Complete |

Switch languages using the dropdown in the top utility bar.
